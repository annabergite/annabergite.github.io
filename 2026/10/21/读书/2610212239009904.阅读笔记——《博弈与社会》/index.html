2026 年 2 月

我前段时间阅读了《博弈与社会》，发现博弈论真的是个好东西

喜好

博弈论让我们做好选择，做好每一步的动作，首先对于那些有价值的选择/事情，肯定人们会有更喜欢，怎么选择自己更喜欢的结果，就是博弈论正在做的事情

（当然出现的循环喜好，比如喜欢梨>香蕉>橙子>西瓜>梨）这部分会优先进行舍弃，因为对我们设计博弈规则有误导，所以需要进行舍弃，对剩下的信息进行处理

为了能达到纳什均衡/帕累托最优，博弈规则会尝试进行帕累托改进

我这边先尝试分分类

博弈的主要分类

常见场景

区分场景，事情至少有三个层次，一个是他知道，一个是我知道，一个是我知道他知道，这个时候就有了博弈的思路了，最多再有一个他知道我知道，我知道他知道我知道这几个层次，再超过就不好判断了

（那个信息最终绝对不透明，是相对于我们生活中的设计，因为确实存在这种情况）

| 信息是否透明\博弈次数 | | 静态博弈（过程一次动作） | | 动态博弈（过程多次动作） | | 重复博弈（相同博弈重复多次） |
| 信息透明 | | 石头剪刀布 | | 一个居于规则的处理，如象棋 | | 打很多遍围棋或者石头剪刀布 |
| 信息不透明 | | 暂无/购买东西 | | 二手车市场/保险服务 | | 职场合作 |
| 信息最终绝对透明 | | —— | | 暂时没想到 | | 长久亲密关系 |

应对策略

| 信息是否透明\博弈次数 | | 静态博弈（过程一次动作） | | 动态博弈（过程多次动作） | | 重复博弈（相同博弈重复多次） |
| 信息透明 | | 随机动作 | | 根据最终收益最大的选择进行反推 | | 最后一次必然背叛 |
| 信息不透明 | | 确保自己利益最大化 | | 品牌效应，权威第三方 | | 看情况/约定社会准则 |
| 信息最终绝对透明 | | —— | | —————— | | 看情况/约定社会准则 |

有一些通用方式进行博弈论的应对策略，比如本身品牌效用和权威第三方的使用范围就很广

重复博弈则会有以下几个具体情况（其实这几种场景可以同时出现，可能同时，可能在不同时间进度下不一样）

| 情况 | | 使用模型 | | 做些什么 | | 应用场景 |
| 是否担心贴现率/是否足够有耐心+完全信息 （或者是合作的可行性分析） | | 无名氏定理 | | 可以合作，让合作带来的未来收益足够大，从而降低短期背叛的诱惑 | | 成熟市场双寡头/验证可行性 |
| 信息微小不确定+足够有耐心 | | KWRW | | 让对方相信有长期合作意愿，诱使对方前期选择合作，释放出不确定一定的非理性 | | 新进入者与在位企业 |
| 信息严重不确定+长期可以揭示 | | 贝叶斯博弈模型 | | 优先小项目合作，根据反馈信息逐步更新自己的模型判断 | | 长期贸易伙伴 |
| 参与人无法处理大量信息 | | 不完美监控/KW2W | | 简化策略，引入可验证外部信号 | | 日常交往 |
| 具体操作 | | 以牙还牙/赢保输改/善意以牙还牙 | | 第一次必然合作，但是后续遇到背叛，则下一次必然背叛他，之后继续合作 | | 日常交往 |

重复博弈代表着有可行性分析（无名氏定理）先判断是否可行，再有KWRW/KW2W/贝叶斯进行模型设计，再有一些具体操作进行操作处理

很有可能，在持续尺度上，小尺度=动态博弈/重复博弈，中尺度：动态博弈，长尺度：演化博弈

其他的，还有演化博弈，也就是一个群体中，持有某种策略的人的群体会变化，可能会被新的替代，可能不断的出现动态平衡

其他重要的信息

  • 贴现因子：贴现因子小就是有人觉得未来收益没那么大，在当前的资金上贴现少，此时这个人就会考虑利益最大化，包括但不限于背叛，没耐心；但是如果贴现因子大，就是有人觉得未来收益大，在当前资金上贴现极大，代表这个人更有耐心，更会有长期合作
  • 信号博弈，比如我学习很多，只是为了拿到一个学历，但是这个学历不是为了证明我有知识，代表我愿意浪费我的时间去获取这么一张文凭，给别人的信号就是自己有资质，有合作意向，同时，比较好的外形与意愿度，行贿送礼等也是这个范畴
  • 通过最终结果反推第一步操作：如果对方是理性人，那他就会尝试自己利益最大化，反推他的最后一步，就能知道他会做什么，反推我的最大化利益的最后一步，尝试找到分歧点。可信威胁，承诺的可信性
  • 信息不对称：信息分为事前信息不对称和事后信息不对称，也就是事前不知道情况，或者时候不知道对应人的情况，两者经常重复出现
  • 激励相容：创造让对方说实话，合作环境氛围
  • 纳什均衡，帕累托改进，帕累托最优
  • 共同知识/信念与信念的层级
  • 焦点/可验证性
  • 时间一致性与承诺能力
  • 协调/动态过程（这一段需要主要进行学习）
