二、gin —— 轻量 Web 框架

特点：轻量、高性能、路由强大，只做 Web 层，ORM 等其它组件自己搭配。国内使用极广。

gin 关键点速记

概念 说明
gin.Default() 带默认中间件的引擎
gin.New() 空引擎，自己加中间件
c.Param(":id") 路径参数
c.Query / DefaultQuery URL 查询参数
c.PostForm 表单参数

c.Next() / c.Abort() 中间件控制
gin.H map[string]any 别名，快速构造 JSON

三、ghttp —— GoFrame 框架的 HTTP 模块

注意：ghttp 不是独立库，是 GoFrame（gf） 全家桶里的 HTTP 组件。GoFrame 是国产重型框架，自带 ORM、缓存、日志、配置、i18n 等，ghttp 是它的 Web 层。

定位区别：gin = 轻量单点；GoFrame = 一站式全家桶。

ghttp 关键点速记

概念 说明
g.Server() 获取默认 HTTP Server
s.BindHandler 绑定路由
r.Get("key") 万能取值，路由/query/form 通吃，比 gin 省心
r.Response.WriteJson 输出 JSON
g.Map map[string]any 别名（对应 gin 的 gin.H）
s.Group 分组路由
Hook 机制 比 gin 中间件更细，可挂在 HookBeforeServe 等节点
全家桶 可顺便用 gdb(ORM)、gcache、glog、gcfg 等

四、学习建议

  1. 先跑通语法：把第一部分每个小例子复制到 main.go，go run main.go 跑一遍。
  2. gin 和 ghttp 选一个先学：
    • 只想做 HTTP 接口、上手快 → gin
    • 想要一个框架搞定 ORM/配置/日志/缓存 → GoFrame ghttp
  3. 对比着记：两者核心都是「路由 → 拿参数 → 返回 JSON」，只是 API 名字不同。
