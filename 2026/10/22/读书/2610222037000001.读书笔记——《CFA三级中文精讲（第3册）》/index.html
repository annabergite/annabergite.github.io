第9章 另类投资的组合管理

9.1 另类投资概述

9.1.1 另类投资的特点（共性）

  1. 流动性差：无活跃交易市场 → 有流动性溢价补偿，收益普遍高于传统投资。
  2. 分散化效果：与传统股票债券相关性低。
  3. 尽职调查成本高：结构策略复杂，依赖经验技能，信息不透明。
  4. 业绩衡量困难：难以找到有效参照标准（benchmark）。
  5. 信息有效性低：有机会获得超额收益。

9.1.2 另类投资的分类

  • 按传统/现代维度：
    • 传统另类投资：私募股权、大宗商品、房地产（与实体经济相关）。
    • 现代另类投资：依赖电子化系统和金融工具，更依赖投资工具与策略。
  • 按组合中的作用（3类）：
    1. 提供不同于股票债券的风险敞口（房地产、大宗商品，实物形态）。
    2. 提供专业化投资策略（对冲基金、管理型期货，收益取决于经理技能）。
    3. 结合以上两者（私募基金、困境公司证券）。

9.1.3 尽职调查要点

共性问题（机构+高净值客户都关注）：

  • 市场机会（识别市场无效性及原因，超额收益能否持续）
  • 投资过程（基金经理优势）
  • 组织架构（健全稳定、薪酬公允、人员流动性）
  • 人员（性格、经验、天赋、品格，背景调查）
  • 条款和结构（公允性、利益关联）
  • 服务提供者（律师、审计师、主经纪商）
  • 文件（招股说明书等）
  • 记下来（书面记录投资讨论）

个人客户特有：

  • 税收（有限合伙制的税费处理不同）
  • 适合性（投资期限和流动性需求随时变化）
  • 交流（非专业投资者难理解复杂问题）
  • 决策风险（在亏损最大时改变策略的风险；负偏态 + 高峰度时决策风险高）
  • 集中性（客户资产集中，如股权、大量房地产）

核心-卫星法（core-satellite）：核心=被动/风险可控主动投资（国债、高市值股票）；卫星=获取超额收益+降低风险（选择与核心相关性低的投资）。另类投资适合放在”卫星”位置。

9.2 房地产（Real Estate）

9.2.1 分类

  • 直接投资：实物房地产（住宅、商业、农业土地）。
  • 间接投资：
    • 上市房地产开发/管理公司股票（如万科）
    • REIT（权益型直接投资房产收租金+升值；抵押型发放抵押贷款收利息）
    • CREF 混合地产基金（非公开交易，机构/高净值，可开放可封闭；封闭式杠杆更高、要求更高收益）
    • 独立管理账户 SMA（类似 CREF，面向高净值）
    • 基础设施基金（政府租用并支付租金）

9.2.2 特征

  • 实物市场缺乏流动性、资金规模和交易成本高。
  • 不同质性（heterogeneity）、不可移动性（immobility）、信息透明度低（卖方信息多于买方）→ 谁能低成本掌握信息谁获益。
  • 利率通过直接/间接方式影响房地产供需。
  • 收益与 GDP 变化成正比，长期人口增长正面影响。
  • 受**特定变量（idiosyncratic variables）**影响（如地理位置）→ 靠全球投资完成完全分散化。
  • 抗通胀（inflation-hedging）：通胀上升时租金可上涨；但合约期内租金固定（类似债券、无抗通胀作用），合约到期重签时可随通胀上涨。

9.2.3 直接投资的优缺点

优点：

  1. 税费抵减（tax deductible，抵押贷款利息、财产税等）。
  2. 可用更高杠杆（抵押贷款）。
  3. 有控制权（直接决策扩张/装修）。
  4. 分散不同区域可降低巨灾风险。

缺点：

  1. 不可拆分、投资额大 → 组合占比高、风险集中。
  2. 每处房产独一无二 → 信息成本高。
  3. 经纪人佣金高。
  4. 持续经营维护成本（管理、租赁、维修），需实际管理经验。
  5. 周围环境恶化风险（不受控制）。
  6. 个人税收减免政策面临政策变化风险。

9.2.4 业绩参照标准

指数 投资类型 权重 频率 特点
NCREIF 直接投资 价值权重 每季度 基于估值（appraisal-based/smoothed），滞后、低估波动、不可投资；另有基于交易的非平滑指数（回归法）
NAREIT 间接投资 市值权重 每月 含所有公开交易 REIT

历史表现（1996–2015）：REIT 收益高（10.3%）但波动大（20.1%）；直接平滑指数波动低（4.6%）；非平滑直接投资的波动（16.3%）约为平滑后 4 倍，收益从 9.9% 降至 8.3%。

9.2.5 组合中的作用

  • 与其他资产相关性不高，波动性小于其他资产；商业地产租金现金流稳定 → 提升组合收益。
  • 加入 10% REIT 后组合风险调整收益变化不大（0.93 → 0.92）→ REIT 分散化作用有限。
  • 不同类型、不同地域房地产之间也有分散化作用（零售业风险调整收益高，写字楼低）。
  • 直接房地产投资可提供一定抗通胀作用。

9.3 私募股权（Private Equity / Venture Capital）

9.3.1 概念

  • 投资于非上市公司股份，私下募集、监管较少，投资者为机构和高净值客户。
  • 两种方式：面对面直接投资；通过私募基金间接投资。
  • 本章侧重：风险投资（VC，早期公司融资） 与 并购基金（buyout funds，成熟公司并购）。

9.3.2 上市公司 vs 非上市公司股权投资

非上市（直接） 上市
交易结构与估值 投资者与管理层谈判 市场决定，结构标准化
信息获取 可要求全部信息（含内部规划） 只能公开信息
投资后活动 进入董事会、参与经营管理 不在董事会、不参与决策

9.3.3 风险投资的阶段

形成阶段（早期）：

  • 种子期（seed）：只有一个想法，出资人=FF&F（创始人的朋友家人）、天使投资人、VC。
  • 启动期（start-ups）：产品研发+初期市场营销，pre-revenue，出资人=天使+VC。
  • 第一阶段（first stage）：初始生产/销售。

扩张阶段（后期）：

  • 第二阶段：第一轮扩张，投资人=VC+战略投资人。
  • 第三阶段：第二轮扩张。
  • 夹层/IPO前（mezzanine/pre-IPO）：为 IPO 做准备，股权+债权结合（过桥 bridge）。

资金提供方：天使投资人（最早外部投资者、金额小、风险最高）；风险资本（VC fund，有限合伙制，占董事会席位）；大型公司（corporate venturing，战略投资者，不向公众开放）。

9.3.4 并购基金（Buyout Funds）

  • 规模约为 VC 基金 2~3 倍；以 AUM 或承诺资本衡量。
  • 中等规模并购基金：购买已成立公司/大公司剥离部分。
  • 超大规模并购基金（mega-cap）：上市公司私有化。
  • 增加收益方式：识别机会低价买入、债务重组。
  • 实现收益方式：IPO、卖出公司、股息资本重构（dividend recapitalization）（发债获得现金并以股利发放给股东，所有权不变，但会使公司承受过高杠杆）。

9.3.5 私募股权投资的类型与费用

  • 直接投资主要通过可转换优先股（convertible preferred stock）：付给普通股股东现金前，先返还优先股股东初始投资的倍数（如2倍）；清算时优先求偿权。
    • 例：投资20万占股20%，公司价值100万。公司以120万卖出：优先股先拿 2×20=40万，剩余(120-40)×20%=16万，共56万，占47%。公司价值越高，普通股回报越接近20%。
  • 间接投资通过私募基金（VC/并购基金），通常有限合伙制（LP）或有限责任制（LLC），存续期710年（可延长15年）。
    • 避免双层征税；LP 最大损失不超过投资额；GP 负责挑选目标公司并出资 → 利益捆绑。
  • 费用结构：
    • 管理费：基于承诺投资金额（非实际投资），通常 1.5%~2.5%。
    • 绩效奖（incentive fee / carried interest）：通常 20%，可设最低回报率（hurdle rate/preferred return）。
    • 追索/回拨条款（claw-back provision）：投资者未收回本金和应有收益时，经理需返还部分金额。

9.3.6 私募股权投资的特征

  • 流动性差、投资期长、投资风险高、内部要求回报率高、信息非常有限（估值需很多假设）。
  • VC vs 并购基金：
    1. 并购基金杠杆较高（成熟公司可抵押资产借债）；VC 一般不用杠杆。
    2. 并购基金更早收回现金、现金流更稳定；VC 前期”烧钱”（cash-burning），后期成功退出收益迅速积累。
    3. VC 收益更难衡量、误差大。
    • 结论：投资越早期，风险越大，潜在收益越高。

9.3.7 参照标准与组合作用

  • 市场价格仅在特定事件（新融资、收购、上市、失败）时才可获得 → 用内部收益率（IRR）衡量。
  • 主要参照：Cambridge Associates 与 Thomson Venture Economics 指数（VC/并购基金）+ 定制化指数。
  • 短期 VC/并购收益低于纳斯达克/标普500，但5/10/20年期均高于（投资期限长）。
  • 分散化作用中等（与上市公司股票相关性 moderately high，但 not extremely high）：
    • 原因：① 企业都面临经济和行业风险敞口；② 上市是 VC 退出的主要渠道。
  • 投资注意：充分分散化（可用 fund of funds，但收两层费用）、流动性（7~10年）、承诺资本条款（capital call，承诺期5年）、合适的分散化策略（行业/阶段/地理）。

9.4 大宗商品（Commodity Investments）

9.4.1 分类

  • 直接投资：现货市场购买实物（有储存成本 → 偏向衍生品市场）；衍生品市场获得敞口（实物/现金交割，多数到期前反向合约抵消）。
  • 间接投资：购买相关公司股票/大宗商品基金。但股票价格不完全取决于大宗商品价格（如中石油股价与油价非完全正相关）→ 不能有效获得敞口 → 越来越多投资者直接投衍生品。

9.4.2 特征

  1. 风险特征：与股票债券相关性极低。
    • 收益影响因素：
      • 经济周期相关的供需。
      • 便利收益率（convenience yield）：持有现货的非货币好处；存货越低、短缺可能性越大 → 便利收益越高。
      • 实物期权（real option）：生产者选择生产/不生产的权利。
  2. 抗通胀：
    • 股票债券与非预期通胀负相关（抗通胀弱）。
    • **不可储存（non-storable）**大宗商品（农产品、家畜）与非预期通胀负相关 → 抗通胀差。
    • **可储存（storable）**大宗商品（能源、贵金属）与非预期通胀正相关 → 抗通胀好（能源最强）。
    • 判断标准：① 是否可储存；② 是否与经济活动紧密相关。

9.4.3 组合中的作用

  1. 风险分散化；2. 抗通胀（抵消非预期通胀损失）。适合养老金（负债与通胀挂钩）、大学捐赠基金（运营费用对通胀敏感）。

9.5 对冲基金（Hedge Funds）

9.5.1 按投资策略分类

  1. 市场中性策略（equity market neutral）：同时买卖股票使系统性风险为零；机会来自自由多空 + 市场无效（被高估股票因禁止做空回归更慢）。
  2. 可转换套利（convertible arbitrage）：买可转债+卖股票对冲；可转债=债券+看涨期权。
  3. 固定收益套利（fixed-income arbitrage）：识别高估/低估固定收益证券，多空中和市场变动影响。
  4. 困境证券（distressed securities）：投资濒临破产公司证券，流动性差难做空 → 通常多头。
  5. 并购套利（merger arbitrage / deal arbitrage）：买入被收购方股票、卖出收购方股票。
  6. 对冲股票（hedged equity）：类似市场中性但不使风险为零，头寸可能过于集中；是最主要策略。
  7. 全球宏观策略（global macro）：全球投资，自上而下，大量使用衍生品。
  8. 新兴市场（emerging markets）：通常禁止卖空 → 以多头为主。
  9. 基金中的基金（FOF）：投资10~30个对冲基金，收两层费用。

其他分类：相对价值（relative value）、事件驱动（event driven）、股票对冲（equity hedge）、全球资产配置、卖空（short selling）。

9.5.2 薪酬结构

  • 管理费 1%~2%（基于 AUM）+ 绩效奖 20%。
  • 门槛收益率（hurdle rate）：达到最小收益率才发绩效奖。
  • 最高水位线（high-water mark, HWM）：业绩超过历史最好才发奖。绩效奖 = 20% × (期末NAV − HWM)。防止同一收益发两次奖。
    • 例：收益15%超过 HWM，”1%管理费+20%×15%=4%”；未超过则只有1%管理费。
  • 管理费较低的基金更有动力获得高收益；历史业绩优秀的经理绩效奖比例更高。
  • 锁定期（lock-up period）：规定最短投资期限（1~3年），期间不能赎回；FOF 一般无锁定期（需预留 cash buffer，降低收益）。
  • 费率争议：高费用结构对应更高收益要求/类似保险费（保护下跌风险）。

9.5.3 基金中的基金（FOF）

  • 委托专业经理筛选对冲基金，降低尽调成本，适合资产量小投资者。
  • 两层费用；无锁定期 → 预留现金降低收益率。
  • 幸存者偏差更小 → 更能准确预测未来收益。
  • FOF 风险因子会经常变化 → 不适合加入大类资产配置。

9.5.4 对冲基金指数

  • 构建考虑：选择标准、风格分类、加权方式、调整方案、可投资性。
  • 每日发布：HFR；每月发布：CISDM（麻州大学）、Credit Suisse、Hedge fund Intelligence、Hedge fund net、Morningstar MSCI。
  • 指数存在的问题：
    1. 流行偏差（popularity）：市值权重易被表现好的基金占据；等权重可避免但调整成本高。
    2. 历史业绩相关性：波动性是更一致的指标，用过去收益预测未来不可靠。
    3. 幸存者偏差（survivorship bias）（最大问题）：只包含存活基金，误差每年 1.5%~3%。
    4. 滞后价格偏差（stale price bias）：非主要问题。
    5. 回填/纳入偏差（backfill/inclusion bias）：加入指数时纳入过去好业绩 → 高估历史收益。

9.5.5 历史表现与组合作用

  • 长期对冲基金业绩优于除房地产外的其他资产；与标普500相关系数0.74（2008年危机升至0.82）。
  • 不同策略风险收益相关性差异大（市场中性、固收套利与股票债券相关性小；事件驱动相关性高）→ 策略间有分散化作用。
  • 对冲基金收益往往负偏态、高峰度（与投资者期望相反）；全球宏观策略正偏态（但高峰度）、市场中性可降波动和峰度。

9.5.6 业绩衡量的其他问题

  • 只看绝对收益（absolute return）即可；超额收益需参照标准。
  • 系统性风险模型针对 long-only 股票组合，不适用于多空策略。
  • 两个手段建立可比组合：单/多因素模型；追踪类似收益风险特征的组合。
  • 自身特点影响业绩：锁定期越长表现越好、越年轻越好、规模越小越好。
  • 起始年份（age/vintage effects）：经济萧条时开始的基金与经济繁荣时无可比性（类比酿酒葡萄年份）。
  • 评判经理业绩因素：收益率、波动率（含下行风险）、评判方法、相关系数（正态分布下才有意义）、偏度和峰度、一致性。

9.5.7 对冲基金收益与风险计算

  • 收益：月度收益 =（期末价值−期初价值）/期初价值；年化按12个月连续复利（季度按4个）。
  • 杠杆/衍生品只影响权重、不影响收益（假设全部自有资金投入）。
  • 移动平均（rolling return, RR）：判断收益率一致性、识别周期性。
  • 波动率：年化标准差 = 月度标准差 × √12（假设月收益序列不相关 + 正态分布）。
  • 跌势差（downside deviation）：只衡量低于门槛值的偏离；门槛为月收益均值时=半方差（semideviation）。
  • 回撤率（drawdown）：最高水位与最低点差值；最大回撤（maximum drawdown）=高水位与之后最低点的最大差额。

9.5.8 业绩衡量指标

  • 夏普比率（Sharpe ratio） = (组合收益 − 无风险利率) / 标准差。缺点：受时间影响（年化=月度×√12）、只适用对称分布、流动性差平滑数据→低估风险→高估比率、序列相关→低估标准差、未考虑相关性、对预测无帮助、可被操纵（增加计量周期/复利收益不复利标准差/卖出价外期权/平滑收益/去除极端收益）。
  • 索提诺比率（Sortino ratio） = (年化收益 − 年化无风险利率) / 跌势差。
  • 收益/损失比（gain-to-loss ratio） = (产生正收益月份次数×平均正收益)/(产生负收益月份次数×平均负收益)，越高越好。

9.6 管理型期货基金（Managed Futures）

9.6.1 与对冲基金比较

  • 相同：私下募集、主动管理、有限合伙制、只向合格投资者开放、薪酬类似（2-20）。
  • 最大区别：管理型期货大部分时间只投资衍生品市场（远期/期货/期权）；对冲基金现货市场更活跃，衍生品只用于对冲。
  • 对冲基金侧重个股（微观、更无效市场）；管理型期货侧重广泛期货期权市场/一篮子资产（宏观指数）。

9.6.2 投资类型

  • 一般合伙人=商品基金经理（CPO），可能由商品交易顾问（CTA）组成；需在 CFTC 注册、NFA 会员。
  • 交易策略：
    • 系统性交易策略：按模型交易，多数 CTA 用趋势追踪法（trend-following），分短/中/长期趋势，也可逆趋势。
    • 自主交易策略（discretionary）：可自主判断（基本面数据等）。
  • 按市场：金融市场、货币市场、分散化市场。

9.6.3 特征

  • 衍生品是零和游戏 → 无杠杆被动投资长期收益=无风险利率−管理费−交易成本。
  • 套期保值者出让收益获得确定性 → 付风险溢价给流动性提供者 → 有足够套保者时管理型期货才能获超额收益。
  • 可做空 → 市场下滑也能获利；可进入期权市场获得波动收益。

9.6.4 组合作用

  • 最大好处：很好的分散化。市场上升时与股债正相关，下降时负相关。
  • 2008年金融危机时期表现较大正收益、低波动，与其他资产负相关。

9.7 困境证券（Distressed Securities）

9.7.1 分类与标的

  • 按结构：对冲基金结构（最主要，流动性高，管理费基于AUM、绩效奖不设门槛）；私募基金结构（固定期限、封闭式）；混合型（hybrid）。
  • 投资标的：公开交易的困境债券股票、孤儿股权（orphan equity）、银行/供应商债权、最终借款人债券、对冲衍生品。

9.7.2 特征与策略

  • 特征：因监管/IPS 限制，债券降级为投机级（堕落天使 fallen angels）后投资者必须卖出 → 低价 → 有动力投资。流动性差；收益呈尖峰肥尾（positive kurtosis）+负偏态（negative skewness）。
  • 4种投资策略：
    1. 多头策略（long-only value investing）：买被低估困境证券；公开债券=高收益投资，孤儿股权=孤儿股权投资。
    2. 困境债券套利（distressed debt arbitrage）：低折扣买破产公司债券+卖空普通股（债券优先级高于股票）。
    3. 私募股权（主动策略）：超低价买入成为主要债权人，参与经营提高公司价值。
    4. 预先打包破产（prepackaged bankruptcy）：债券转股票，好转后卖出。
    • 前两种为短期（对冲基金结构），后两种为长期主动（私募股权结构）。
  • 风险：事件风险（event risk，公司特有、与系统风险相关性低）、市场流动风险（最主要）、市场风险、J因素风险（法官对破产判决的影响）。

9.7.3 参照标准与历史表现

  • 平均收益高于股票债券，但负偏态 → 大亏损可能性大。
  • 风险调整收益基于正态假设 → 不适合衡量困境证券。
  • 策略取决于经济周期：经济疲软 → 破产增加 → 投资机会增加；事件风险预测能力不完全体现在业绩中。

第10章 风险管理

10.1 风险管理概述

10.1.1 核心理念

  • 风险管理不是消除所有风险（不承担风险就没有收益），而是投资过程的组成部分；更像风险修正（risk modification），既可减少也可增加风险（risk expansion）。

10.1.2 风险管理流程（5步）

  1. 确定方法、制定流程（制定风险管理准则 policies + 流程 procedures）。
  2. 确定风险承受能力（意愿 willingness + 能力 ability）。
  3. 识别风险。
  4. 衡量风险大小。
  5. 调整风险大小（通过衍生品或其他交易）。
    • 选择”最合适”交易工具：模型定价 vs 市场价。买入工具时市场价低于预估才划算；卖出工具时市场价≥预估才合适。完成后回到第4步度量风险。

10.1.3 风险治理（Risk Governance）

  • 评判维度：透明性、责任明确、有效性（达成目标）、效率性（有效利用资源）。
  • 集中化风险管理（ERM，enterprise risk management）：
    • 优点：全局视角、规模效应降成本、部门间风险对冲（A部门做多+B部门做空=无敞口）、各风险分散化（整体风险<单个加总，如10年融资vs180天融资利率相关性非完全）。
  • 分散化风险管理：风险管理责任分散到各部门，负责人更贴近风险源头、更熟悉业务。
  • 有效的风险治理要求：交易部门与风险管理部门相互独立；后台部门完全独立于前台部门。
    • 后台（back office）：事务处理、记录保管、合规管理；前台（front office）：交易、销售。
  • 有效 ERM 系统步骤：识别所有风险 → 量化风险为金额 → 公司层面估算（VaR）→ 评估总风险及每种风险贡献 → 建立向高管汇报流程 → 监控执行。

10.1.4 风险识别

金融风险：

  • 市场风险：利率、汇率、股价、大宗商品价格变化（与供需挂钩）。
  • 信用风险：对手方/债务人未履约造成的损失。
  • 流动性风险：不能及时以合理价格买卖。用买卖价差衡量（价差小=流动性好，但只适用小部分情况）；成交量（trading volume）是更好指标。流动性风险难衡量，往往不良事件发生时才出现；衍生品不能有效管理资产流动性（基础资产流动性出问题，衍生品也会出问题）。

非金融风险：

  • 操作风险：电脑系统、操作过程（人为错误）、外部不可控事件。应对：监控、预防、预案、保险。
  • 模型风险：模型使用方法不当或错误模型（衍生品/无报价产品依赖模型定价）。
  • 结算风险（settlement risk）：一方履约而对手方未履约。交易所/清算中心、净额结算、CLS（持续联系结算）可减少；外汇交易（时区不同）风险更大；Herstatt 风险（德国 Herstatt 银行破产案例）。
  • 监管/政策风险：监管政策变动。
  • 法律/合约风险：法律体系不能保证对手履约。
  • 税务风险、会计风险。
  • 主权风险（sovereign risk）：债务人是国家（信用风险一种），需分析财务状况+还款意愿+政治环境。
  • 政治风险：政治环境变动。

其他风险：

  • ESG 风险：环境、社会、治理漏洞导致的市值下跌。
  • 业绩净额风险（performance netting risk）：多策略基金中一策略赚钱一策略亏损但净收益为零，仍要付赚钱策略奖金 → 最终亏损（不对称绩效结构导致）。
  • 净额结算风险（settlement netting risk）：破产清算时净额结算在不同法律体系执行不同。

10.2 风险度量：市场风险

10.2.1 敏感度指标

  • 一阶线性：股票 beta、债券久期（duration）、期权 delta。
  • 二阶非线性：债券凸性（convexity）、期权 gamma。
  • 其他：theta（剩余到期日）、vega（标的波动率）。

10.2.2 VaR（在险价值）

  • 定义：未来特定时间、一定概率水平（常见1%或5%）下的预期最大损失。
  • 两种解释（例：市值10亿，一周5%概率 VaR=200万）：
    • 最小亏损角度：一周内有5%可能性最小损失（至少）200万。
    • 最大亏损角度：有95%可能性最大损失不超过200万。
  • 注意：同置信水平才可比、明确时间段、针对亏损取绝对值、单尾检验。
  • 使用关注3点：概率水平（1% VaR 损失 > 5% VaR 损失）、时间段（公司选季度/年匹配报表周期；基金/高杠杆选天）、估计方法。

10.2.3 计算 VaR 的3种方法

  1. 分析法（方差-协方差法，variance-covariance）：
    • 假设收益正态分布。VaR = |−μ + zσ|（5%: z=1.65；1%: z=2.33，单尾）。
    • 例：μ=16%，σ=25%，市值3亿：VaR(%)=−16%+1.65×25%=25.25% → 7575万。
    • 时间转换：年=日×√250，年=月×√12，年=周×√52（假设250交易日、数据独立）。
    • 组合方差：σ²p = w²Aσ²A + w²Bσ²B + 2ρwAwBσAσB。
    • 优点：简单易懂；缺点：依赖正态假设（期权组合不服从正态、尖峰肥尾低估亏损），可用**一阶常态法（delta-normal）**修正含权组合；资产多时标准差计算复杂。
  2. 历史模拟法（historical）：非参数法，不假设分布；将 N 个历史收益排序，5%×N 临界值即 VaR。优点：简单、不假设正态；缺点：假设历史代表未来。
  3. 蒙特卡罗模拟法（Monte Carlo）：电脑模拟路径产生随机结果，取最低第（5%×样本数）个数据。优点：不要求输入变量正态。

10.2.4 VaR 的优缺点

优点：行业标准（监管要求）、清晰明了、应用灵活（按投资活动/经理分类）、可事前计算用于资本配置（风险预算 risk budgeting）。
缺点：估算困难（不同方法结果不同）、误以为风险被准确衡量、只衡量亏损不反映上升潜力、低估亏损严重程度与频度。

  • 需持续回溯测试（backtesting）：5%概率每天VaR=100万 → 一年约 250×5%=12.5 天亏损超100万，差距大说明模型不准。
  • 其他补充指标：
    • 增量 VaR（IVaR）：加入新资产后组合 VaR − 之前 VaR。
    • 现金流风险（CFAR）：一段时间给定概率下最小现金流亏损。
    • 利润风险（EAR）：按会计利润计算。
    • 尾部风险（TVaR）：最差5%结果的平均值。

10.2.5 压力测试（Stress Testing）

  • 场景分析（scenario analysis）：
    1. 程式化情景（stylized scenarios）：行业标准，如 DPG 1995 年7种情景（利率曲线平行±100bps、非平行twist±25bps、两者4种组合、隐含波动率±20%、股票指数±10%、主要货币±6%其他±20%、互换利差±20bps）。缺点：变量变动呈现顺序而现实中同时发生。
    2. 真实的极端事件（科技泡沫、911、次贷危机）。
    3. 假设的极端事件。
  • 压力模型（stressing models）：不预测具体数值而预测范围。3种方式：
    1. 因素推进法（factor push）：设置极端不利条件（缺陷：假设极端下模型仍适用，否则产生模型风险）。
    2. 最大损失优化（maximum loss optimization）：数学优化风险因子得到损失最大情景。
    3. 最差情景分析（worst-case scenario）。

10.3 风险度量：信用风险

10.3.1 基础概念

  • 信用风险损失从两方面衡量：违约概率、违约后损失（可回收比率 recovery rate，难估计）。
  • 信用风险数据有限（事件少、历史可回收率不可靠）。
  • 现时信用风险（current credit risk / JTD risk）：违约马上发生；潜在信用风险（potential credit risk）：未来可能违约。
  • 交叉违约条款（cross-default provisions）：对某一义务违约即对所有义务违约。
  • 只有持有头寸价值大于零的一方才面临信用风险。

10.3.2 信用 VaR

  • 一段时间、一定概率下因信用风险导致的最小亏损。
  • 与市场 VaR 不能完全分割；信用 VaR 对应收益分布右尾（正收益方），市场 VaR 对应左尾。
  • 更难估计（数据缺乏）；不同信用风险难加总（相关性需考虑）。

10.3.3 各类衍生品的信用风险

  • 远期合约：期初价值为零；期间盈利方有潜在信用风险（账面收益）；到期结算时存在现时信用风险。期货（交易所交易）信用风险默认为零。
    • 远期求价值：多头的价值 = 向上箭头现值 − 向下箭头现值（股票/债券远期扣除股利现值；外汇远期用各自币种利率折现+即期汇率统一货币；FRA 用名义本金+利率折现）。
  • 互换合约（=一系列远期）：每个结算日有现时信用风险，期间价值=潜在信用风险。
    • 利率/权益互换：潜在信用风险最大在合约中期（期初双方做了信用分析、临近到期现金流减少）；净额结算时只有收款方（盈利方）面临信用风险。
    • 货币互换：期初/期末交换本金，本金远大于期间现金流，货币不同无法净额结算，双方都面临信用风险，最大在中后期。
    • 利率互换注意：浮动利率债券在结算日价值回归面值（=1）；利息由上一结算日决定。
  • 期权：单边信用风险（unilateral credit risk）——只有买方面临信用风险（买方期初付期权费后无义务）。欧式期权到期前只有潜在信用风险（现值=当时期权价值）；美式期权价值更高、潜在信用风险更高，提前行权则面临现时信用风险。

10.4 风险的管理

10.4.1 管理市场风险

  • 风险预算（risk budgeting）：关注”想承担哪方面风险””如何分配”。两个层面：公司层面、组合管理层面。
    • 各部门风险预算之和 > 公司总风险预算（分散化作用）。
    • 用 return on VaR 等风险调整收益比较各基金经理。
  • 其他方法：止损线（performance stopout）、营运资本分配（working capital allocation）、VaR限制、情景分析限制、风险因子限制、头寸集中度限制、杠杆限制、流动性限制。

10.4.2 管理信用风险

  • 限制每个主体的风险敞口（分散化，但”太多”难量化）
  • 盯市（marking to market）
  • 抵押物（collateral）
  • 结算轧差（payment netting）
  • 出清轧差（close-out netting）
  • 最低信用要求（minimum credit standards；SPV/EDPC 提高评级）
  • 信用衍生品（CDS、总收益互换、信用利差期权、信用利差远期）

10.4.3 业绩衡量（风险调整）

  1. 夏普比率 SR = (R_p − R_f)/σ_p。
  2. 风险调整资本收益 RAROC = 预期收益/风险资本（如 VaR）。
  3. 最大回撤收益 RoMAD = 平均收益/最大回撤率。
  4. 索提诺比率：分子=预期收益−最小可接受收益（MAR），分母=下行标准差。
  5. 信息比率：每单位主动风险的超额收益。

10.4.4 资本分配（5种方法）

  1. 按名义金额/持有资金量（简单但不考虑风险）。
  2. 按 VaR 分配（考虑风险，但需 VaR 准确、不易被交易员理解、总体与单个 VaR 关联复杂）。
  3. 按最大亏损分配（不能太高/太低，极端情况易被打破）。
  4. 内部资本要求。
  5. 监管资本要求（银行、券商）。
  • 注意管理者利益冲突：薪酬与业绩挂钩 → 无动力最小化风险，反有动力提高风险。

第11章 风险管理的应用：衍生品

核心视角：衍生品是管理风险的工具，而非投机工具。对冲（hedge）锁定不确定性（回避损失也失去收益）；管理风险（manage risk）更进一步，可减少也可增加风险头寸。

11.1 远期和期货在风险管理中的应用

11.1.1 管理利率风险（调整久期）

  • 债券利率风险=久期风险。预期利率上升 → 减久期；预期利率下降 → 增加久期。
  • 用债券期货调整组合久期：
    • 美元久期 = 修正久期 × 价格。
    • 组合美元久期 = 债券美元久期 + 期货美元久期。
    • 公式：N = (MDUR_T − MDUR_B) / MDUR_f × (B/f) × β_y
      • MDUR_T：目标修正久期；MDUR_B：债券修正久期；MDUR_f：债券期货修正久期；B：债券价格；f：期货价格；β_y：收益率贝塔（yield beta）= Δy_B/Δy_f（债券利率变化对期货基础资产利率变化的敏感度）。
    • 完全对冲：目标久期=0。
    • 例：B=5000万，f=7.5万，MDUR_B=5.5，MDUR_f=7.5，β_y=1.05。目标6 → 买46.67≈47份；目标4 → 卖140份。

11.1.2 管理股票市场风险（调整贝塔）

  • 分散化组合用贝塔衡量风险（侧重系统性风险）。
  • 公式：β_T×S = β_S×S + N_f×β_f×f → N_f = (β_T − β_S)/β_f × S/f
    • β_T：目标贝塔；β_S：股票组合贝塔；β_f：股指期货贝塔（不一定等于1）；S：组合市值；f：期货价格。
    • 完全对冲：目标贝塔=0（卖期货）。
  • 期货价格通过点位×乘数表示（如标普500，1点=250美元）；不同指数乘数不同。
  • 成长股组合只能用成长股股指期货管理风险。
  • 有效贝塔（effective beta）：对冲后组合真实贝塔 = 组合实际收益率/市场收益率，用于评判风险管理有效性（四舍五入等原因导致不完全等于目标贝塔）。

11.1.3 合成股票头寸（synthetic index fund）

  • 基础公式：买入股票 + 卖出期货 = 买入无风险资产 → 买入股票 = 买入无风险资产 + 买入期货。
  • 用股指期货将现金头寸合成股票头寸（省成本、流动性好、到期自动回归现金）。
  • 计算3要素：需要多少份期货、期初投资多少本金、相当于购买多少份股票（考虑股利再投资）。

11.1.4 合成现金头寸

  • 买入股票 + 卖出期货 = 买入无风险资产，将股票头寸合成为现金头寸（不用卖股票、降成本）。

11.1.5 管理组合的资产配置

  • 债券与股票之间转换（如60/40→50/50）：先确定转换金额，再用股指期货去除股票风险敞口（β=0），用债券期货加债券风险敞口（久期=目标值），以现金为桥梁（现金 β=0、久期=0）。
  • 不同股票类型之间转换（大盘股→小盘股）：先用大盘股期货调 β=0，再用小盘股期货调至目标 β。
  • 用远期/期货调整的优势：避免交易费用、流动性高（尤其相对债券）；局限：只调整系统性风险忽略非系统性风险、依赖 β/久期估计偏差、四舍五入影响。

11.1.6 提前投资（pre-investing）

  • 预期未来收到现金，根据市场预期买入合约（期初无现金流出，期货保证金由其他账户满足）。

11.1.7 外汇风险（国际贸易公司角度）

  • 经济风险（economic exposure）：汇率变化影响竞争力（如美元升值→美国出口企业竞争力下降）。无法对冲。
  • 折算风险（translation exposure）：合并国外子公司报表时汇兑损益变化，只是会计风险，不对冲也不能对冲。
  • 交易风险（transaction exposure）：以外币计价的应收/应付账款因汇率变动产生的风险。可对冲：应收账款→卖出合约；应付账款→买入合约。

11.1.8 对冲的限制

  • 国外投资面临国外市场风险 + 汇率风险。可对冲两种/一种/都不对冲。
  • 只对冲汇率风险：期末价值不确定 → 无法确定对冲本金。处理：预期未来价值对冲；设最小值对冲。都不尽如人意；两种风险都对冲则市场风险对冲后值确定，汇率对冲更容易。

11.1.9 远期 vs 期货

  • 远期 OTC 定制化、不受约束、有违约风险；期货交易所标准化、受监管、无违约风险。
  • 实务：FRA 常用于对冲借款利率风险；债券市场偏向期货；外汇市场偏爱远期；做市商喜欢欧洲美元期货（交易量大）。

11.2 期权在风险管理中的应用

11.2.1 期权策略在股票组合中的应用

（1）持保看涨期权（covered call）= 买入股票 + 卖出看涨期权

  • 适用：预期股票价格短期平稳。
  • 收益 Π = −[Max(0,S_T−X) − C_0] + (S_T − S_0)。
  • 最大收益（S_T≥X）= X + C_0 − S_0；最大亏损（S_T=0）= C_0 − S_0；盈亏平衡点 S_T = S_0 − C_0。

（2）保护性看跌期权（protective put）= 买入股票 + 买入看跌期权

  • 看跌期权多头=保险。
  • 收益 Π = (S_T − S_0) + [Max(0,X−S_T) − P_0]。
  • 最大收益无限（S_T>X）= S_T − S_0 − P_0；最大亏损（S_T≤X）= X − S_0 − P_0；盈亏平衡点 S_T = S_0 + P_0。
  • 代价：期权费贵；执行价格越高（保护越大）期权费越贵。
  • 期权费关系：看跌执行价越高期权费越贵；看涨执行价越低期权费越贵。

（3）价差（spread）策略

  • 时间价差（到期时间不同，三级不讨论）；货币价差（money spread，执行价格不同，重点）。
  • 牛市价差（bull spread）：买低执行价看涨 + 卖高执行价看涨（C_L > C_H）。
    • 收益 Π = [Max(0,S_T−X_L)−C_L] − [Max(0,S_T−X_H)−C_H]。
    • 最大收益（S_T≥X_H）= X_H − X_L + C_H − C_L；最大亏损（S_T≤X_L）= C_H − C_L；盈亏平衡 S_T = X_L + C_L − C_H。
    • 用看跌期权构建牛市价差：卖高执行价看跌（获利）+ 买低执行价看跌（对冲），P_H > P_L。最大收益 = P_H − P_L；最大亏损 = X_H − X_L + P_L − P_H；盈亏平衡 S_T = X_H + P_L − P_H。
  • 熊市价差（bear spread）：卖低执行价看涨 + 买高执行价看涨。与牛市价差相反（熊市获利）。
    • 关系：long bull call spread = short bear call spread；long bull put spread = short bear put spread。
  • 蝶式价差（butterfly spread）= 买入牛市价差 + 买入熊市价差（3个执行价 X_L<X_M<X_H）。
    • 头寸：买 X_L 看涨 + 卖2份 X_M 看涨 + 买 X_H 看涨。
    • 收益 Π = [Max(0,S_T−X_L)−C_L] − 2[Max(0,S_T−X_M)−C_M] + [Max(0,S_T−X_H)−C_H]。
    • 适用：预期价格波动平稳（S_T=X_M 时最大收益 = X_M−X_L−C_L+2C_M−C_H）；最大亏损 = 2C_M−C_L−C_H。
    • 预期波动剧烈则卖出蝶式价差。

（4）跨式期权（straddle）= 买入同执行价看涨 + 看跌

  • 适用：预期市场有波动但方向不确定。
  • 最大亏损 = C + P（价格不变）；价格持续上涨时收益无限。
  • 盈亏平衡：S_T<X 时 = X − C − P；S_T>X 时 = X + C + P。
  • 宽跨式期权（strangle）：两期权执行价格不同（图形底部为平滑线）。

（5）保护性封顶保底策略（collar）

  • = 保护性看跌 + 卖出看涨（用卖出看涨的期权费支付看跌期权费）。期权费相同=零成本 collar。
  • 核心头寸是股票现货，看跌执行价通常低于看涨执行价。
  • 收益 Π = (S_T−S_0) + [Max(0,X_P−S_T)−P] − [Max(0,S_T−X_C)−C]。
  • 最大收益（S_T≥X_C）= X_C + C − S_0 − P；最大亏损（S_T≤X_P）= X_P + C − S_0 − P；盈亏平衡 S_T = S_0 + P − C。

（6）盒式套利（box spread）= 牛市价差 + 熊市价差

  • 损益确定不变：Π = (X_H − X_L) − (C_L − C_H + P_H − P_L)。
  • (X_H−X_L) 为期末价值/收入；(C_L−C_H+P_H−P_L) 为构建成本。
  • 合理定价时收益=无风险收益率；收益>无风险利率 → 成本低（多头低估/空头高估）→ 买入低估、卖出高估套利；收益<无风险利率 → 反向头寸。
  • 有效组合：box spread = long bull call spread + long bear put spread；或 = long bear call spread + long bull put spread。

11.2.2 利率期权策略

  • 利率看涨期权：基础利率>执行利率有收益；利率看跌期权：基础利率<执行利率有收益。
  • 收益 = 名义本金 × Max(0, 到期基础利率 − 执行利率) × (贷款期限/360)。
  • 利率看涨期权在借款中的作用（借款人担心利率上升）：
    • 实际借款利率 = 实际支付的利息/实际拿到的本金。
    • 期权费需时间调整（按 LIBOR+利差 复利到借款日），从借款金额扣除。
  • 利率看跌期权在贷款中的作用（贷款人担心利率下降）：
    • 期权费时间调整后加到贷款金额（都是贷款人现金流出）。
    • 锁定收到利息下限 = 执行利率 + 利差。
  • 利率上限（interest rate cap）：对冲多笔利息的一系列利率看涨期权；组成单元=利率上限单元（caplet）。利率下限、上下限原理类似（上下限需同时考虑上下限结算金额）。
    • 关键：利率在期初确定、期末结算；第一笔利息利率已知（0时刻）→ 无需期权，只需 3 个 caplet（针对后3笔）。

11.2.3 期权组合的风险管理策略（做市商角度）

  • 看涨期权空头收益有限、亏损无限。3种对冲方法：找相反头寸抵消（难）；买卖权平价合成（麻烦）；delta 对冲（最常用）。
  • Delta 对冲：delta = Δ期权价格/Δ基础资产价格。对冲1份看涨期权空头需买入 delta 份基础资产；对冲1份看跌期权空头需卖出 delta 份基础资产。
  • 动态对冲（dynamic hedge）：delta 随市场环境、时间改变而变化 → 不断调整头寸。原因：delta 是一阶线性（凸性问题）、delta 本身会变、四舍五入。
  • 完美对冲时组合收益=无风险利率；不等则对冲不完美。
  • Gamma：delta 对基础资产价格的敏感度。平价期权接近到期时 gamma 最大、风险最大 → gamma 对冲比 delta 对冲更重要。

11.3 互换在风险管理中的应用

11.3.1 利率互换（管理利率风险）

  • 单纯利率互换（plain vanilla）：固定换浮动。
  • 互换久期：D_swap = D_fixed − D_float（付固定方）或 D_float − D_fixed（收固定方）。
    • 浮动利率债券付息日久期≈0；两付息日之间久期=到下次付息时间或平均久期（季度付息平均0.125年）。
    • 固定利率债券久期 = 到期时间 × 0.75（季度付息）。
  • 增加久期 → 收固定互换；降低久期 → 付固定互换。
  • 名义本金公式：V_p×MDUR_T = V_p×MDUR_P + NP×MDUR_swap → NP = V_p × (MDUR_T − MDUR_P)/MDUR_swap（名义本金与互换久期负相关）。
  • 浮动/固定利率贷款转换：付固定借款 + 收固定付浮动互换 → 变浮动负债。将浮动负债转固定负债=把现金流风险（cash flow risk）换成市场价值风险（market value risk）——现金流不确定性消除（利于预算），但久期上升、市值波动加剧。
  • 降低所有者权益久期：增加负债久期（付浮动收固定互换）。
  • 管理结构性债券风险（杠杆化浮动利率债券、反向浮动利率债券）：用固定利率债券 + 互换对冲。要点：确定买入固定利率债券面值倍数、进入何种互换、承担两个对手方违约风险。

11.3.2 货币互换（管理汇率风险）

  • 货币互换可固定换固定/固定换浮动/浮动换浮动（汇率不确定）。
  • 改变负债币种：国内发本币债券 + 货币互换 → 外币负债（降低国外融资成本）。期间利息差额=信用风险溢价成本。
  • 不交换本金的货币互换：锁定每期现金流转换金额。风险：实际现金流与预期不一致。

11.3.3 权益互换（管理股票市场风险）

  • 不买卖股票获得/转移股票头寸（暂时性）。
  • 应用：管理市场风险（支付股票收益+收固定利息，把股票头寸变固定收益头寸）、组合分散化、国际化分散化（付国内收益换国外指数收益，交易成本低但有外汇风险）、改变资产配置（股股/债债/股债转换）。
  • 特点：可能出现付两份/收两份（指数收益为负时收两份）；支付两份可能现金流不足需卖股票。

11.3.4 利率互换期权（Swaption）

  • 互换期权=进入互换合约的权利。支付互换期权（payer swaption）：有权支付固定、收浮动；收到互换期权（receiver swaption）：有权收固定、付浮动。
  • 性质类似期权：买方付期权费、分美式/欧式、有执行利率。
  • 市场利率>执行利率 → payer swaption 行权（类似利率看涨期权）；市场利率<执行利率 → receiver swaption 行权（类似利率看跌期权）。
  • 对冲将来借款利率风险：未来付浮动利率 → 买 payer swaption（预期利率上升时按固定付有利）。
  • 提前终止互换：买入与现有合约头寸相反、特征相同的互换期权。
  • 合成增加/去除看涨期权特征：
    • payer swaption ~ 利率看涨期权 ~ 债券看跌期权。
    • receiver swaption ~ 利率看跌期权 ~ 债券看涨期权。
    • 去除可赎回债券（callable bond）的看涨性质：short callable bond = short receiver swaption。
    • 加入看涨性质：long callable bond = long receiver swaption。

第12章 交易

12.1 市场结构与交易成本

12.1.1 市场功能（3方面）

流动性（liquidity）、透明性（transparency）、确保交易的完成性（assurity of completion）。

12.1.2 市场结构（4种）

  • 指令驱动型市场（order-driven）：价格受买卖指令影响，交易在投资者间进行（不通过做市商）。订单竞争激烈→更好价格执行，但流动性弱→可能延迟/无法成交。成交规则：价格优先、时间优先。
    • 子分类：电子交互网络（electronic crossing networks，成批处理、成本低、信息保密、但可能不完全执行、无价格发现功能）；拍卖市场（auction markets，有价格发现）；自动拍卖市场（如 ECN，连续竞价、有价格发现、信息保密）。
    • 市场指令（market order）：以当前最好价格立即成交，重速度 → 价格不确定（price uncertainty）。
    • 限价指令（limit order）：只以约定或更好价格成交 → 执行不确定（execution uncertainty），存在隐性机会成本。
  • 报价驱动型市场（quote-driven / dealer markets）：做市商提供买卖价，赚买卖价差，为买卖双方提供流动性。流动性差市场（如债券）以做市商为主；信用有时比价格更重要。
  • 经纪人市场（brokered market）：经纪人代表做市商寻找对手方，服务大单（block order）保密订单（防抢单 front-run）。
  • 混合市场（hybrid）：前三者组合。

12.1.3 有效价差（effective spread）

  • 买入价（bid）=做市商愿意买入的价格；卖出价（ask/offer）=做市商愿意卖出的价格。
  • 内部买入价（inside bid）=最高买入价；内部卖出价（inside ask）=最低卖出价；内部价差（inside bid-ask spread）越小流动性越高；中间价（midquote）=买卖价均值。
  • 有效价差 = 2 × |执行价格 − 中间价|（买单：2×(执行价−中间价)；卖单：2×(中间价−执行价)）。
  • 有效价差 < 市场价差 → 交易成本低、有价格改善（price improvement）。
  • 有效价差优于市场价差：可反映价格改善和大单对市场的改变（market impact）。
  • 平均有效价差：分批执行时计算，可简单平均或成交量加权。

12.1.4 评判市场质量的标准

  1. 流动性：较小买卖价差、较大市场深度（market depth，大单不改变价格）、市场有弹性（market resilience，价格与内在价值差距小、回归快）。影响因素：买卖双方数量、投资者/观点多样化、交易便捷性、市场诚信与监管。
  2. 透明性：获得信息难易（交易前价量+交易后信息）。
  3. 完成性：合约双方履行义务，经纪商和交易所提供保证。

12.2 衡量交易成本的方法

12.2.1 交易成本分类

  • 显性成本（explicit costs）：佣金、税费、印花税（可直接观测）。
  • 隐性成本（implicit costs）：买卖价差、市场冲击成本/价格影响、未成交的机会成本（missed trade opportunity costs）、延迟成本（delay costs/slippage）。
  • 隐性成本计算（用参照价格）：
    • 买单 = 交易量 × (执行价格 − 参照价格)。
    • 卖单 = 交易量 × (参照价格 − 执行价格)。
    • 参照价格：开盘价、收盘价或 VWAP。

12.2.2 VWAP（成交量加权平均价格）

  • VWAP = Σ(P_i × Q_i)/ΣQ_i（权重=各笔交易量占总交易量比例）。
  • 作为参照价格衡量隐性成本。
  • 缺点：① 交易员订单占市场绝大部分时会严重影响 VWAP（执行价≈VWAP，隐性成本看似为零但实际很高）；② 容易被操纵（可预测 VWAP 并延迟到第二天执行）。

12.2.3 执行落差（Implementation Shortfall, IS）

  • 定义：真实组合收益与假设组合（paper portfolio，订单立即全部执行、无费用）收益之差，包含所有显性+隐性成本。
  • 决定价格（decision price）：通常为前一天收盘价（或题目给定）。
  • 假设组合收益 = 订单数 × (交易期末市场价格 − 决定价格)。
  • 4个组成元素：
    1. 显性成本：佣金、税费。
    2. 实现的损益（realized profit/loss）：执行价格与决定价格（若延迟执行则为第一天收盘价）之差 × 执行股数。
    3. 延迟成本（delay costs）：下单当天未成交带来的成本 =（第一天收盘价 − 决定价格）× 执行股数。
    4. 未实现损益/机会成本：（取消时价格 − 决定价格）× 取消股数。
  • 总执行落差 = 假设组合收益 − 真实组合收益；百分比 = 总执行落差/假设组合总成本。

12.2.4 调整市场变动的执行落差

  • 市场变动是交易员无法掌控的，应剔除。E(R_i) = α_i + β_i×E(R_M)，日收益 α_i≈0。
  • 调整后执行落差 = IS − β×市场收益（负数=对组合是收益）。

12.2.5 VWAP vs 执行落差

  • VWAP 优点：好理解、计算简单、快速决策，适用无趋势市场的小单。
  • VWAP 缺点：不适大单、易被操纵、不能衡量延迟成本/机会成本/市场冲击成本。
  • 执行落差优点：衡量所有成本、可分解、不易被操纵、可在快速执行与市场冲击间权衡。
  • 执行落差缺点：计算繁琐、需大量数据。

12.2.6 计量模型（econometric models）

  • 多元回归预测交易成本；影响因素：流动性、风险程度、市场走势、交易量大小、交易风格。
  • 用途：评判交易质量、调整交易规模。

12.3 交易者的类型

  1. 信息驱动型（information-motivated）：拥有信息、机会稍纵即逝，重速度、用市场指令、要求高流动性、注意隐藏动机。
  2. 价值驱动型（value-motivated）：寻找高估/低估证券，不常交易，重价格、用限价指令。
  3. 流动性驱动型（liquidity-motivated）：变现满足现金需求/调仓，是前两者的天然对手方。
  4. 被动交易者（passive）：指数基金投资者，重成本不重速度。
  • 其他：做市商（赚价差）、套利者（价格和速度都重要）、日内交易员（几秒/几分钟快速买卖）。

12.4 交易策略

  • 专注流动性（liquidity-at-any-cost）：牺牲成本换快速执行（信息驱动型）。
  • 成本不重要（cost-are-not-important）：市场有效、执行价已最好。
  • 需要可信代理人（need-trustworthy-agent）：大单需经验经纪商（时间长，不适合信息驱动型）。
  • 广而告之（advertise-to-draw-liquidity）：公开吸引投资者（可能泄露信息、抢跑）。
  • 低成本优先（low-cost-whatever-the-liquidity）：限价指令最小化成本（被动/价值驱动型）。

12.5 算法交易（Algorithmic Trading）

  • 目的：最小化交易成本（非获得超额收益），对大单分割执行。

12.5.1 逻辑参与策略（重点）

  • 简单逻辑参与策略：
    1. VWAP 策略：按历史日交易量分配订单，匹配日平均交易价。
    2. TWAP 策略（时间加权平均价格）：按时间权重平均分配（适用交易量小的资产）。
    3. POV 策略（成交量百分比）：按市场总交易量份额拆分（活跃多下单，不活跃少下单）。
  • 执行落差策略（arrival price strategy）：最小化执行落差（尤其市场冲击+机会成本）；早期多成交（front-loaded）；风险厌恶越高越早交易；适用于转化管理（transition management）。

12.5.2 机会主义与特殊策略

  • 机会主义策略：被动投资同时捕捉主动机会。
  • 特殊策略：猎人策略（hunter）、市场收盘策略（market-on-close，以收盘价执行）。

12.5.3 算法交易策略选择

  • 订单规模占总交易量比率高 → 算法交易不适用，选择经纪商/交易平台。
  • 占比低且价差小 → 算法交易；紧急程度高 → 执行落差策略；紧急程度低 → 简单算法策略。

12.6 最优执行（Best Execution）

  • 目的：最有利方法买卖证券，提高组合收益、履行受托责任。
  • 4个特征：
    1. 不能独立于投资决策（需考虑投资策略，如信息驱动型需快速执行）。
    2. 事前无法知晓（买卖双方博弈共同决定）。
    3. 只能事后评判，需看长期表现而非单次交易。
    4. 交易是一个复杂的、持续性的过程。
  • 定义困难：合适参考标准难找、隐性成本难衡量、大单拆小后成本计算难、”最优”本身因人而异。

第13章 业绩评估

13.1 组合业绩评估

13.1.1 两大角度与三大结构

  • 基金发起人角度（外部）：业绩评估是反馈机制，识别投资项目好坏、决定经理去留。
  • 基金经理角度（内部）：自我评价、改进投资过程。
  • 三大结构：
    1. 业绩测定（performance measurement）：账户价值变化 → 收益率。
    2. 业绩归因（performance attribution）：收益来源（板块选择/个股选择）。
    3. 业绩评估（performance appraisal）：收益受投资决策还是市场环境/运气影响。

13.1.2 收益计算

  • 无外部现金流：r = (MV_1 − MV_0)/MV_0。
  • 期初外部现金流 CF：r = [MV_1 − (MV_0+CF)]/(MV_0+CF)。
  • 期末外部现金流 CF：r = [(MV_1−CF) − MV_0]/MV_0。
  • 期间现金流：以现金流发生点为界分段计算再衔接。

13.1.3 时间加权收益率（TWR）

  • TWR = (1+r_1)(1+r_2)…(1+r_n) − 1。
  • 每1单位资金在投资期的复合增长率，不受外部现金流时间/规模影响。
  • 需大量数据（data intensive and expensive）。

13.1.4 货币加权收益率（MWR）

  • 账户内部收益率（IRR），受外部现金流时间/规模影响。
  • 只需期初/期末市值。适合基金经理能控制现金流时间的账户（如部分对冲基金、LLP）。
  • 市场上涨前追加投资 → MWR > TWR；下跌前追加 → MWR < TWR。

13.1.5 衔接的内部收益率（LIRR）

  • 每个子时间段用 MWR 计算再几何衔接 ≈ 近似 TWR。
  • 适用：外部现金流规模较小、投资收益稳定（若现金流>10%账户总值或收益剧烈波动则差异大）。

13.1.6 数据质量

  • 流动性差/交易不频繁资产价值难估计（相似产品报价、成本价/历史价、直接猜测）。
  • 需考虑交易日会计（trade date accounting）、应计利息股息（accrued interest and dividends）。
  • 全价 = 净价 + (t/T)×C（t=交易日距上次付息时间，T=两次付息间隔，C=每期息票）。

13.2 组合收益的构成

  • P = M + S + A，即 P = M + (B−M) + A。
    • M：市场指数收益；S = B−M：基金经理投资风格；A = P−B：主动管理超额收益；B：参考基准收益。
    • 例：P=4.2%，B=4.5%，M=3.3% → S=1.2%，A=−0.3%。

13.3 参考基准

13.3.1 有效参考基准的7类特征

  1. 事先明确（specified in advance）
  2. 合适的（appropriate，符合投资风格）
  3. 可衡量的（measurable）
  4. 清楚的（unambiguous，可复制）
  5. 反映当前投资观点（reflective of current investment opinions）
  6. 拥有性及可说明性（owned and accountable）
  7. 可投资的（investable）

13.3.2 7种主要基准参考指标

基准 优点 缺点
绝对值（absolute） 简单直观 不可投资、不满足多数特性
基金经理基准比较（manager universes） 可计量 存在偏差（后文重点）
广义市场指数（如S&P500、MSCI） 认可、易懂、易获取、清楚可投资 风格可能与经理不符
风格指数（style indices） 认可、易懂 可能含过多权重证券/板块、风格定义差异
因子模型（factor-model-based） 有效评估、洞察风格 不为人熟知、数据昂贵、结果差异
基于收益的基准（returns-based） 直观、符合多数特性 可能含过多权重板块、需大量月度数据
自定义证券（custom security-based） 符合所有条件、持续监管、有效分配风险预算 构建维护成本高、缺乏透明性
  • 自定义基准构建步骤：确认投资过程重要元素 → 选证券 → 分配权重 → 回顾调整 → 定期再平衡。

13.3.3 对”基金经理经验领域”的批判

  • 除可测量性外不满足其他优秀性质；不确定、不能事前知晓、不可投资。
  • 存在存活偏差（survivor bias）：发起人终结差经理 + 经理选择不披露差业绩 → 基准定制过高。

13.3.4 参考基准质量的检验

  1. 系统性偏差（systematic bias）：回归 R_B = a + βR_P + e，β显著≠1 说明存在系统性偏差。好的基准：A（主动超额）与 S（风格超额）无关联；S 与 E（P−M）高度相关。
  2. 追踪误差（tracking error）：A 的标准差，越小越好；S_(P−B) < S_(P−M)。
  3. 风险特性：账户系统性风险来源应与基准一致（长期相等）。
  4. 覆盖率（coverage）：相同证券占账户市值百分比，越高越反映风格。
  5. 周转率（turnover）：被动组合基准应低周转。
  6. 多头的主动仓位（positive active positions）：应有大量多头主动仓位；大量空头说明基准未反映风格。

13.4 对冲基金业绩的衡量方法

  • 多空组合初始市值可能近似为零 → 收益率公式失效。
  • 价值增加收益法（value-added return）：R_VA = R_p − R_B，对每只证券超额收益加总。
  • 缺陷：难区分主动决策超额收益与做空能力；无特定风格的对冲基金无法找到可比对象。
  • 也有人用夏普比率比较（但收益有偏、标准差衡量风险存疑）。

13.5 业绩归因

13.5.1 宏观业绩归因（基金发起人角度）

  • 3类输入变量：政策分配（policy allocations）、参考基准组合收益（benchmark portfolio returns）、基金收益/估值/外部现金流。
  • 6个层次（从初始市值到最终市值）：
    1. 净贡献（net contributions）：外部现金流总和。
    2. 无风险资产（risk-free asset）：0~M’ 部分。
    3. 资产类别（asset categories）：M’~W，R_AC = Σ w_i(R_M,i − R_F)。
    4. 参考基准（benchmarks level）：W~B，R_B = ΣΣ (w_i)(w_ij)(R_B,ij − R_M,i)。
    5. 基金经理（investment managers）：B~P，R_M = ΣΣ (w_i)(w_ij)(R_P,ij − R_B,ij)。
    6. 分配效应（allocation effects）：调平项。

13.5.2 微观业绩归因（基金经理角度）

  • 价值增加收益来自：行业选择、个股选择、交集。
  1. 单纯板块分配（pure sector allocation） = Σ (w_pj − w_bj)(R_bj − R_B)。
  2. 板块内部选择（within-sector selection） = Σ w_bj(R_pj − R_bj)。
  3. 分配/选择交叉收益（allocation/selection interaction） = Σ (w_pj − w_bj)(R_pj − R_bj)。
  • 经验法则：加大对表现优异板块投资 → 高收益；减少 → 低收益；加大对表现拙劣板块投资 → 低收益；减少 → 高收益。

13.5.3 基本面因子模型

  • 多因子回归：R_p = a + b_1F_1 + … + b_nF_n + ε。
  • 主动收益 = (a−a’) + Σ(b_i−b’_i)F_i，其中 (b_i−b’_i) 为主动敞口，(b_i−b’_i)F_i 为超额收益来源。
  • 4类超额收益技巧：市场择时（market timing，含现金头寸+Beta择时）、基本面因子敞口（成长、规模、杠杆、收益率因子）、经济板块因子敞口（行业）、特殊/无法解释的收益。
  • 主动影响 = 主动敞口 × 风险因子。

13.5.4 固定收益组合回报归因

  • 两大部分：外部利率环境影响 + 管理过程贡献。
  • 外部利率环境影响：预期利率影响（远期隐含收益率）+ 非预期利率影响（实际 vs 远期差异）；以无风险债券为基准，被动投资即可获得。
    • 远期利率：(1+S_2)² = (1+S_1)(1+f)。
  • 管理过程贡献（4部分）：
    1. 利率管理影响（interest-rate management effect，含久期、凸性、收益率曲线形状）。
    2. 板块/质量管理影响（sector/quality management effect，板块利差+资产质量）。
    3. 证券选择影响（security selection effect）。
    4. 交易活动（trading activity，无法解释部分）。

13.6 风险调整后的业绩鉴定衡量

13.6.1 5种指标

  1. 事后 α（ex-post alpha） = R_p − [R_f + β_p(R_M − R_f)]。α>0 位于 SML 上方。
  2. 特雷诺衡量（Treynor） = (R_p − R_f)/β_p（每单位系统性风险的超额收益）。
  3. 夏普比率（Sharpe） = (R_p − R_f)/σ_p（每单位总风险的超额收益，CML 斜率）。
  4. 信息比率（IR） = (R_p − R_B)/σ(R_p−R_B)（每单位主动风险的超额收益）。
  5. M² 衡量 = R_f + (R_p − R_f) × (σ_M/σ_p)（组合风险调整为与市场一致时的收益）。M²>市场收益 → 位于 CML 上方。

13.6.2 指标比较

  • α 和 Treynor 基于系统性风险 β：α>0 ⇔ Treynor > 市场 Treynor；最高 α 不一定最高 Treynor。
  • Sharpe 和 M² 基于总风险：Sharpe 大 → M² 大。
  • 对 α/Treynor 的批评：CAPM 只假设一个市场风险；用标普500代表市场；忽略交易成本；事后结果未来可变。
  • 高指标组合不一定高回报（低风险组合可有高 α/Sharpe 但低绝对收益）。

13.7 质量控制图（Quality Control Charts）

  • 假设：预期价值增加收益为零（原假设 H0：经理无能力）；价值增加收益独立且服从正态；投资过程稳定。
  • 价值增加线持续高于红线（基准收益）→ 优秀；随机分布 → 运气。
  • 95% 数据落在均值±2标准差；大量数据持续落在置信区间上方 → 5%显著性水平拒绝原假设。

13.7.1 基金经理续用政策（MCP）

  • 目的：留用优秀/解雇糟糕经理、多方面评估、最小化不必要轮转、关注账户成长性。

13.7.2 第一类错误与第二类错误

  • 第一类错误：留下没有增加价值的经理（错误拒绝真实原命题）。
  • 第二类错误：解雇能带来价值的经理（未拒绝虚假原命题）。
  • 记忆：解雇好经理=主公误杀忠臣，非常”二” → 第二类错误。

第14章 全球投资业绩准则（GIPS）

14.1 简介

14.1.1 适用范围与目标

  • 适用主体：拥有投资业绩的投资公司（制造业企业如可口可乐不能声称遵守 GIPS）。
  • 自愿遵守的准则。
  • 目标：建立全球业绩计算与披露的行业惯例、促进客户获得准确业绩陈述、促进行业比较、鼓励完整披露与公平竞争、鼓励自我监管。
  • 当前版本 2010 年版（2011年1月1日生效）；英语版本是官方指定版本。
  • 与当地法律冲突时遵守法律并披露冲突。

14.1.2 专业术语

  1. 阐离（carve out）：从原组合中分割单独管理的部分；除非有自己的现金余额，否则不能从原组合中割离（防虚报业绩）。
  2. 组合（composite）：具有相同投资风格、目的、策略的组合类别（虚拟概念，是业绩披露单位）。所有 portfolio 必须至少归入一个 composite。
  3. 公司/独立商业主体（firm）：不一定是法人，形式与功能独立、可自主处置资产、有自主投资决策过程即可是 firm（GIPS 适用单位）。
  4. 衔接（link）：数学衔接（几何衔接收益率）+ 表象衔接（两段业绩放一起陈述）。
  5. 合格客户（prospective client）：对组合策略感兴趣且符合投资要求的个人/实体。
  6. Gross-of-fees：扣除交易费用（trading expenses）后收益。
  7. Net-of-fees：gross-of-fees 基础上再扣投资管理费用（含绩效奖/附带权益）。
  8. 托管费用（custody fee）：行政费用，不在 gross-of-fees 中扣减。
  9. 交易日记账（trade date accounting）：以交易日（非交割日）价格入账。
  10. 交割日记账（settlement date accounting）：以交割日价格入账（最新 GIPS 规定用交易日记账）。
  11. 临时新建账户（temporary new account）：显著外部现金流先放入，建仓后再并入原账户。
  12. Vintage year（房地产/私募股权）：基金开始运作收取管理费的年份；判定标准=首次资本召唤年份 或 第一笔承诺资本被锁定受法律约束的年份。
  13. 打包费（wrap fee）：含投资管理费、交易费、托管费、行政费用的组合（养老金账户=SMA/managed account）。
  14. 授权（mandate）：投资者授权基金经理按一定投资风格管理（=对外宣称的投资风格）。

14.1.3 GIPS 概观（9大部分）

  1. Fundamentals of Compliance（遵守基础）
  2. Input Data（输入数据）
  3. Calculation Methodology（计算方法）
  4. Composite Construction（组合构建）
  5. Disclosures（披露）

  7. Real Estate（房地产）

  • 每条分 requirements（必须遵守，考试重点）和 recommended（推荐遵守）。

14.2.2 1. Input Data（输入数据）

必须遵守（关键时间线）：

  • 1.A.1 所有数据必须捕获并保存。
  • 1.A.2 自2011年起按公允价值+估值原则估值。
  • 1.A.3 估值频率：自2001年起至少每月；自2010年起大笔现金流发生日也须估值。
  • 1.A.4 自2010年起日历月结束日或最后营业日估值。
  • 1.A.5 自2005年起使用交易日记账（trade date accounting）。
  • 1.A.6 固定收益证券使用权责发生制，含应计利息。

14.2.3 2. Calculation Methodology（计算方法）

必须遵守：

  • 2.A.1 使用总收益（total returns）。
  • 2.A.2 使用调整外部现金流的 TWR，子期间几何衔接。自2001年至少每月计算；自2005年调整按天加权的外部现金流。
  • 2.A.3 现金及现金等价物收益须包含。
  • 2.A.4 扣减真实交易费用（不可用估计值）。
  • 2.A.5 打包费无法拆分时：gross-of-fees 扣全部捆绑费（或含交易费部分）；net-of-fees 扣全部（含交易费+管理费部分）；不可用估计费用。
  • 2.A.6 组合收益以资产加权（期初价值或期初价值+外部现金流）。
  • 2.A.7 组合收益资产加权：自2006年至少每季度；自2010年至少每月。
  • 收益计算法演进时间线：
    • 2005年前：Original Dietz：R = (EMV − BMV − CF)/(BMV + 0.5×CF)。
    • 2005年后：Modified Dietz：R = (EMV − BMV − ΣCF_i)/(BMV + Σw_i×CF_i)，w_i=(CD−D_i)/CD；Modified IRR：EMV = Σ[CF_i(1+r)^w_i] + BMV(1+r)。
    • 2010年后：TWR（大笔现金流分割子期间，几何衔接）。
  • 组合收益3种计算方法：期初市值加权；期初市值+外部现金流加权；加总收益法（aggregate return）。

14.2.4 3. Composite Construction（组合构建）

必须遵守：

  • 3.A.1 所有付费+自主组合 MUST 至少归入一个组合；非自主 MUST NOT；不付费自主 MAY（需披露）。
  • 3.A.2 只含真实管理的资产（模拟组合不可）。
  • 3.A.3 模拟收益不可与真实业绩衔接。
  • 3.A.4 组合须按投资风格/目标/策略定义；定义改变不可追溯调整。
  • 3.A.5 新组合及时、持续纳入。
  • 3.A.6 已终结组合业绩保留至上一完整评估周期。
  • 3.A.7 组合不可随意在组合间转移（除非风格/目标/策略重大改变或组合重定义）。
  • 3.A.8 自2010年起，carve-out 须有自己的现金余额。
  • 3.A.9 最低资产标准不可追溯调整。
  • 3.A.10 显著现金流须事先定义。
  • large cash flow（针对组合，影响收益计算）vs significant cash flow（针对组合，影响策略执行）。

  • 4.A.11 组合描述清单可得；4.A.12 估值/计算政策可得。

14.2.6 5. Presentation and Reporting（陈述与报告）

    • 每年组合收益（标明 gross/net of fees）。
    • 组合成立/终止时不足1年的期间收益（不可年化）。
    • 每年参考基准总收益。
    • 每年末组合内组合个数（≤5个可不披露）。
    • 每年末组合资产规模。
    • 公司总资产 或 组合资产占公司总资产百分比。
    • 每年内部偏差指标（≤5个可不披露）。
    • 内部偏差5种方法：最高/最低收益、全距（range）、等权标准差、资产加权标准差、四分位全距（interquartile range）。
  • 5.A.2 自2011年起每年末披露组合及基准的3年年化事后标准差（用月度收益）；不适用时提供其他风险衡量（周期须一致）。
  • 5.A.3 2000年后不合规业绩不可与合规业绩衔接（2000年前可，但须披露不合规期）。
  • 5.A.4 不足1年收益不可年化。
  • 5.A.5 carve-out 占组合百分比；5.A.6 不付费组合百分比；5.A.7 打包费组合百分比。
  • 5.A.8 收购公司业绩衔接条件：① 决策人员基本留用；② 决策过程保持完整独立；③ 有业绩记录文件。收购后有1年时间将不合规资产转合规。

  • 6.A.1 自2011年公允价值估值。
  • 6.A.2 自2008年至少每季度估值。
  • 6.A.3 自2010年季度末/最后营业日估值。
  • 6.A.4 外部估值：2012年前至少36个月一次；2012年后至少12个月一次（客户协议可另定但不超过36个月）。
  • 6.A.5 外部估值由独立专业认证评估师执行。
  • 6.A.6 至少每季度计算收益。
  • 6.A.7 扣减真实交易费用（transaction expenses）。
  • 6.A.8 自2011年收入回报与资本回报分开计算（几何衔接 TWR）。
  • 6.A.9 组合及成分收益以资产加权至少每季度计算。
  • 6.A.10~13 披露（自由裁量权、估值方法、外部估值差异、估值频率等）。
  • 6.A.14 须陈述成分收益+总收益。
  • 6.A.15 2006年后不合规业绩不可衔接。
  • 6.A.16 内部偏差用最高/最低年化 TWR；披露外部估值组合占比。
  • 封闭式基金（closed-end fund）：6.A.17 计算 SI-IRR（since inception IRR）；6.A.18 至少季度现金流；6.A.19 按 vintage year+风格/目标/策略定义；6.A.20~22 披露清算日、现金流频率、vintage year；6.A.23 须陈述 net-of-fees SI-IRR（5年+逐年增加）；6.A.24 若陈述 gross SI-IRR 须同陈述 net；6.A.25 披露 TVPI/DPI/PIC/RVPI 乘数；6.A.26 基准 SI-IRR（同风格、同期、同 vintage year）。
  • 房地产收益计算：
    • 动用资本 C_e = C_0 + Σ(CF_i × w_i)。
    • 资本回报 R_C = [(V_1−V_0) − E_C + S]/C_e。
    • 收入回报 R_I = (I − E_D − I_d − T_p)/C_e（毛收入 − 不可回撤费用 − 债券利息 − 财产税）。

14.3.2 7. Private Equity（私募股权）

必须遵守（关键）：

  • 7.A.1 自2011年公允价值估值。
  • 7.A.2 至少每年估值。
  • 7.A.3 计算年化 SI-IRR。
  • 7.A.4 自2011年用每日现金流；股票分配计入现金流并估值。
  • 7.A.5 扣减真实交易费用。
  • 7.A.6 net-of-fees 扣实际管理费（含附带权益）。
  • 7.A.7 FOF 收益扣所有底层合伙/基金费用（含附带权益）。
  • 7.A.8 组合定义保持一致性。
  • 7.A.9 主要基金须归入按 vintage year+风格/目标/策略定义的组合。
  • 7.A.10 FOF 按 vintage year 和/或风格/目标/策略定义。
  • 7.A.11~20 披露（vintage year、清算日、估值方法、估值政策变化、行业准则、基准指数、现金流频率、费用、不合规期）。
  • 7.A.21 须披露5年 net + gross SI-IRR，逐年增加。
  • 7.A.22 FOF 组合仅按风格/目标/策略定义时须另披露按 vintage year 分类的底层投资 SI-IRR。
  • 7.A.23 披露 TVPI/DPI/RVPI/PIC 乘数。
  • 7.A.24~25 基准 SI-IRR（同风格、同期、同 vintage year）。
  • 7.A.26 FOF 组合披露直接投资比例。
  • 7.A.27 主要基金披露投资其他基金比例。
  • 7.A.28 2006年后不合规业绩不可陈述。

14.3.3 8. Wrap Fee / SMA Portfolios（打包费/分开管理账户）

  • bundled fee = all-in fee 和 wrap fee 两大类；wrap fee 以资产价值为基准。
    必须遵守：
  • 8.A.1 实际 wrap fee/SMA 组合业绩须按既定政策归入适当组合。
  • 8.A.2 披露未含真实 wrap fee 组合的期间。
  • 8.A.3 披露2006年前不合规期。
  • 8.A.4 sponsor-specific 组合披露发起人名称、用途限制。
  • 8.A.5 组合须含所有真实 wrap fee 组合（不论发起人）。
  • 8.A.6 业绩须扣减整个 wrap fee。
  • 8.A.7 2006年后不合规业绩不可衔接。

14.4 验证与检查

14.4.1 验证（Verification）

  • 自愿行为；由独立的合格第三方执行（可遵守 GIPS 也可不遵守）。
  • 评估：① 公司层面所有组合构建是否符合 GIPS；② 计算/陈述业绩的政策流程是否符合 GIPS。
  • 单一验证报告针对整个公司，不可针对某一组合。
  • 初始最小验证期：1年（不足1年自成立起）。
  • 验证报告未发布前不可宣称已验证。
  • 可用抽样方法；验证后可能得出不符合 GIPS 的结论（须说明原因）。

14.4.2 业绩检查（Performance Examination）

  • 针对单一组合检验是否符合 GIPS（自愿）。
  • 必须先被验证过才能被检查；验证与检查第三方应为同一主体。

14.5 估值原则（Valuation Hierarchy）

估值层级（级别逐次降低）：

  1. 相同投资品活跃市场的客观可观察未经调整报价。
  2. 相似投资品活跃市场报价。
  3. 相同/相似投资品不活跃市场报价。
  4. 基于市场基础的可观察输入变量（模型估值）。
  5. 主观不可观察输入变量（反映公司自身假设，基于最优可得信息）。
  • 私募股权估值流程考虑：可信赖的估值数据、可比较企业/数据、企业当前发展阶段、企业独特特征。
  • 外部估值师费用不得与估值结果挂钩；推荐以单一数值呈现；每3~5年轮换外部估值师。

14.6 GIPS 广告指导方针

  • 适用对象：公司层面遵守 GIPS 的投资公司；与法律冲突时遵守法律并披露冲突。
  • 广告形式：报纸、杂志、宣传册、信件、媒体及任何书面/电子形式（非一对一）。
  • 广告须披露：
    1. 公司定义。
    2. 客户如何获取标准陈述/组合描述清单。
    3. GIPS 广告合规声明（简练版）：”[公司名] claims compliance with the Global Investment Performance Standards (GIPS®)。”
  • 若广告含业绩披露，额外披露：
    1. 组合描述。
    2. 组合总收益（3种方式之一：1/3/5年年化收益率；期间至今+1/3/5年年化；期间至今+过去5年每年收益率。不足1年不可年化）。
    3. 业绩是 gross 还是 net of fees。
    4. 参考基准总收益；8. 参考基准描述；9. 无基准说明原因。
    5. 货币；11. 杠杆/衍生品/空头头寸；12. 2000年前不合规期；13. 与法律冲突之处。

14.7 税后回报

  • GIPS 不要求提供税后回报，但要求国家倡议者指导税后计算披露。
  • 挑战：基金经理难控制客户指定交易（client-directed trades）、难找合适基准、pre-liquidation 与 market-to-liquidation 未考虑未来收益/损失（未衡量经济价值）。
  • 计算税后收益方法：
    • pre-liquidation：未实现资本收益不征税 → 低估税后影响。
    • market-to-liquidation：所有收益征税 → 高估税收影响。
  • 合适的参考基准：反映客户纳税状态；指数需自行计算税后回报；共同基金有执照费用且收益有别于真实指数、受交易/申赎影响；ETF 不受申赎影响，更合适；最准确的是定制化基准（custom security-based）和影子组合（shadow portfolio，模拟客户买卖现金流）。

附：核心公式速查表

VaR 与风险

  • VaR(%) = |−μ + zσ|（5%: z=1.65；1%: z=2.33，单尾）
  • 年化波动率：年=日×√250 = 月×√12 = 周×√52
  • 组合方差：σ²p = w²Aσ²A + w²Bσ²B + 2ρwAwBσAσB
  • 夏普比率 SR = (R_p − R_f)/σ_p
  • 索提诺比率 = (年化收益 − 年化无风险利率)/跌势差
  • 收益损失比 = (正收益月数×平均正收益)/(负收益月数×平均负收益)
  • Treynor = (R_p − R_f)/β_p
  • 信息比率 IR = (R_p − R_B)/σ(R_p−R_B)
  • M² = R_f + (R_p − R_f) × (σ_M/σ_p)
  • 事后 α = R_p − [R_f + β_p(R_M − R_f)]
  • RoMAD = 平均收益/最大回撤率

衍生品风险管理

  • 债券期货调整久期：N = (MDUR_T − MDUR_B)/MDUR_f × (B/f) × β_y
  • 股指期货调整贝塔：N_f = (β_T − β_S)/β_f × S/f
  • 有效贝塔 = 组合实际收益率/市场收益率
  • 合成股票 = 买入无风险资产 + 买入期货
  • 合成现金 = 买入股票 + 卖出期货
  • 利率互换名义本金：NP = V_p × (MDUR_T − MDUR_P)/MDUR_swap
  • 互换久期：D_swap = D_fixed − D_float（付固定方）
  • 利率期权收益 = 名义本金 × Max(0, 到期基础利率 − 执行利率) × 贷款期限/360
  • 实际借款利率 = 实际支付利息/实际拿到本金

交易成本

  • VWAP = Σ(P_i×Q_i)/ΣQ_i
  • 买单隐性成本 = Q×(执行价 − 参考价)；卖单隐性成本 = Q×(参考价 − 执行价)
  • 有效价差 = 2×|执行价 − 中间价|
  • 执行落差 IS = 假设组合收益 − 真实组合收益
  • 假设组合收益 = Q×(期末价 − 决定价)
  • 实现的损益 = (执行价 − 第一天收盘价)×执行股数
  • 延迟成本 = (第一天收盘价 − 决定价)×执行股数
  • 未实现损益 = (取消价 − 决定价)×取消股数

业绩评估与收益

  • TWR = (1+r1)(1+r2)…(1+rn) − 1
  • Original Dietz：R = (EMV − BMV − CF)/(BMV + 0.5CF)
  • Modified Dietz：R = (EMV − BMV − ΣCF_i)/(BMV + Σw_iCF_i)，w_i=(CD−D_i)/CD
  • 全价 = 净价 + (t/T)×C
  • P = M + S + A = M + (B−M) + (P−B)
  • 单纯板块分配 = Σ(w_pj − w_bj)(R_bj − R_B)
  • 板块内部选择 = Σ w_bj(R_pj − R_bj)
  • 分配/选择交叉 = Σ(w_pj − w_bj)(R_pj − R_bj)
  • 远期利率：(1+S₂)² = (1+S₁)(1+f)

私募/另类乘数

  • TVPI（Investment multiple）= 总价值/实收资本
  • DPI（Realization multiple）= 累计分配/实收资本
  • RVPI（Unrealized multiple）= 剩余价值/实收资本
  • PIC（PIC multiple）= 实收资本/承诺资本
